## PHASE 9: FLATNESS POLISH PASS

*(Run 2)*

Using the Phase 0.9 audit, apply surgical polish. **Do not redesign — polish within the existing system.**

### 9.1 Shadows
- Cards without shadows: add `shadow-sm` + `hover:shadow-lg`
- Navy sections: light shadows or border-only treatment
- Buttons: coral CTA gets `shadow-md hover:shadow-lg`

### 9.2 Hover states
- Nav links: `hover:text-[var(--coral)]`
- Card: `hover:-translate-y-1 hover:shadow-lg transition-all duration-200`
- Buttons: `hover:bg-[var(--coral-hover)]`
- Icon buttons: `hover:bg-[var(--off-white)]`

### 9.3 Border consistency
- All cards use `border border-[var(--border-soft)]`
- Card corners standardized to `rounded-xl`

### 9.4 Icon containers
Where icons sit naked next to text — wrap in:
- `w-10 h-10 rounded-full bg-[var(--coral)]/10 flex items-center justify-center`
- Icon inside: `text-[var(--coral)]`
- Apply across feature cards, contact info, focus area cards

### 9.5 Typography
- One H1 per page
- Section headings = H2 (no H3 where H2 should be)
- Sub-sections = H3
- Body line-height ≥1.6, heading line-height ≤1.2
- Eyebrow labels: `text-xs uppercase tracking-[0.18em] font-semibold`

### 9.6 Spacing rhythm
- Section padding: `py-16 md:py-24`
- Container: `max-w-7xl mx-auto px-6`
- Card grid gap: `gap-6 md:gap-8`
- Between H2 and body: `mt-4`
- Between heading block and cards: `mt-12 md:mt-16`

### 9.7 Image treatment
- Text overlay on image: add `bg-gradient-to-t from-black/60 to-transparent` layer
- Card images: `rounded-t-xl` top corners, consistent aspect ratio in same grid

### 9.8 Micro-interactions
- Buttons and cards: `transition-all duration-200`
- Nav links: `transition-colors duration-150`

### 9.9 Do NOT
- Do not add animations longer than 300ms
- Do not add gradients beyond existing
- Do not change fonts
- Do not add decorative elements not in the reference design
- Do not touch admin pages
